# 🎧 Customer Support Analytics

A Streamlit-based data analytics application designed to analyze customer support tickets, response performance, customer issues, and satisfaction.

## 📌 Project Overview

Customer Support Analytics converts customer support data into an interactive dashboard. It allows users to filter the data, explore important metrics, visualize support performance, and understand customer-related patterns.

## 📊 Application Sections

### 📊 Dashboard
- Interactive filters and KPI metrics for analyzing customer support performance.
- Visual analysis of response time, customer issues, priority, and satisfaction.

### 💡 Insights
- Provides data-driven insights about customers, issues, devices, and customer sentiment.
- Highlights repeat contacts, knowledge base usage, and areas for support improvement.

### 🗃️ Raw Data & Profiling
- Displays the dataset with rows, columns, data types, missing values, and other details.
- Includes statistical summary, unique values, duplicate analysis, and memory usage.

## ✨ Key Features

- 🎯 Ticket and customer filters
- 🎫 Ticket volume and priority analysis
- ⏱️ Response time analysis
- 👥 Top customer and issue analysis
- 📱 Device-wise issue analysis
- 😊 Customer sentiment analysis
- ⭐ Customer satisfaction analysis
- 🔁 Repeat contact analysis
- 📚 Knowledge base analysis
- 📈 Matplotlib visualizations
- 📥 Filtered data download
- 🧹 Data profiling and missing value analysis
